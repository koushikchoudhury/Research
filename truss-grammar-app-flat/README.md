# Truss grammar workbench

Streamlit app: five truss grammar rules with exact checks, a stiffness solver, and a graph-network surrogate.
Run locally: pip install -r requirements.txt, then streamlit run app.py
Main file for Streamlit Community Cloud: app.py
Rules are reconstructed from Fig. 4 of Shea et al., JCISE 25(12), 2025, not taken from the authors' code.
